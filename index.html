How to get your free YouTube API key
  1. Open Google Cloud Console and sign in.
  2. Create a new project, for example "Bruno Vibe".
  3. Open YouTube Data API v3 and tap Enable.
  4. Open Credentials, tap Create credentials, then API key.
  5. Copy the key (it starts with AIza) and paste it in the box below.

Keep your key private. The free quota allows roughly 100 searches a day. The key is saved only on your device.
